# Notepad++ کے لیے AutoIt Tidy فارمیٹر

[English](README.md) · [中文](README.zh-CN.md) · [हिन्दी](README.hi.md) · [Español](README.es.md) · [Français](README.fr.md) · [العربية](README.ar.md) · [বাংলা](README.bn.md) · [Português](README.pt.md) · [Русский](README.ru.md) · [اردو](README.ur.md)

**Notepad++ ٹول بار** سے ایک کلک میں AutoIt کوڈ فارمیٹ کریں — یہ **سرکاری AutoIt3 `Tidy.exe`** (SciTE4AutoIt3 v21.316.1639.1) چلاتا ہے۔
نتیجہ SciTE میں **Ctrl+T** دبانے کے برابر ہے؛ پلگ اِن میں اپنی کوئی فارمیٹنگ لاجک نہیں ہے۔

## خصوصیات

| خصوصیت | رویہ |
| --- | --- |
| انجن | صرف سرکاری `Tidy.exe` (پلگ اِن کے `tidy\` فولڈر میں شامل) |
| دائرہ | صرف **موجودہ ایڈیٹر بفر** فارمیٹ کرتا ہے؛ فائل پڑھتا یا محفوظ نہیں کرتا |
| ایک کلک | ٹول بار بٹن + مینو کمانڈ؛ `.au3` دستاویزات کے لیے کوئی ڈائیلاگ نہیں |
| ایک انڈو | پوری فارمیٹنگ ایک مرحلہ → ایک **Ctrl+Z** سب واپس لے آتا ہے |
| تبدیلیوں کی تاریخ | نارنجی پٹی **صرف واقعی بدلی گئی سطروں** پر دکھتی ہے |
| لائن اینڈنگ | دستاویز کی اصل EOL (LF / CRLF / CR) محفوظ رہتی ہے |
| انکوڈنگ | بفر UTF-8 میں؛ غیر ASCII تبصرے محفوظ |
| کوئی تبدیلی نہ ہو | اگر Tidy کہے «no updates to make» تو بفر اچھوتا رہتا ہے |
| کرسر | کرسر/انتخاب/اسکرول حتیٰ الامکان محفوظ |

Tidy کے سرکاری قواعد لاگو ہوتے ہیں: انڈینٹیشن (ڈیفالٹ ٹیب)، کلیدی الفاظ/فنکشنز/ویری ایبلز کی کیس،
ڈیلیمیٹرز کے ارد گرد اسپیس، سطر کے آخر کی اسپیس ہٹانا، خودکار `EndFunc   ;==>FunctionName`،
`#Region`/`#CE` تبصروں کی ہم آہنگی، اور `;### Tidy Error` جیسے ساختی اشارے۔

## سرکاری Tidy کے ساتھ تصدیق

* **318 حقیقی `.au3` فائلیں**: مواد سرکاری `Tidy.exe` کے آؤٹ پٹ سے **100 % یکساں**۔
* ان میں 317 فائلیں **بائٹ بہ بائٹ یکساں** (لائن اینڈنگ سمیت)۔
* 1 فائل صرف لائن اینڈنگ کے انداز میں مختلف ہے (وہ LF ہے؛ پلگ اِن LF رکھتا ہے، Tidy ہمیشہ CRLF لکھتا ہے)۔

## تنصیب

1. [Notepad-autoit-format (ZIP)](https://github.com/123d56/Notepad-autoit-format/archive/refs/heads/main.zip) ڈاؤن لوڈ کریں۔
2. ان زپ کریں، پھر **`install.ps1` پر رائٹ کلک → Run with PowerShell**۔
   اسکرپٹ Notepad++ خود تلاش کرتا ہے اور ضرورت پر UAC ایلیویشن مانگتا ہے۔
   دستی طریقہ: `AutoItBeautify` فولڈر کو `C:\Program Files\Notepad++\plugins\` میں کاپی کریں۔
3. **Notepad++ مکمل بند کر کے دوبارہ کھولیں** — ٹول بار کے دائیں سرے پر نیلا بٹن ظاہر ہوگا۔

## استعمال

* ٹول بار کا نیلا بٹن، یا مینو **Plugins → AutoIt 美化 → 一键美化 AutoIt 代码（Tidy）** (مینو کے نام چینی میں ہیں؛ کمانڈ ID 22000)۔
* اسٹیٹس بار نتیجہ دکھاتا ہے؛ **Ctrl+Z** ایک مرحلے میں سب واپس لے آتا ہے۔
* اختیاری: **Settings → Shortcut Mapper → Plugin commands** میں شارٹ کٹ مقرر کریں۔

## Tidy کے اختیارات

`%APPDATA%\Notepad++\plugins\Config\AutoItBeautify\tidy\Tidy.ini` میں ترمیم کریں (پہلے استعمال پر خود بنتی ہے)۔

```ini
tabchar=0          ; 0 = ٹیب، >0 = اسپیس کی تعداد
tabsize=4
proper=1           ; کلیدی الفاظ/فنکشنز کی کیس معمول پر لانا
vars=3             ; ویری ایبلز: 1 بڑے، 2 چھوٹے، 3 پہلی بار کے مطابق
delim=1            ; ڈیلیمیٹرز کے ارد گرد اسپیس
endfunc_comment=1  ; "EndFunc ;==>Name" شامل کریں (-1 = بند)
icl_pos=0          ; اِن لائن تبصرہ کالم: 0 = موجودہ رکھیں
```

اسکرپٹ میں Tidy ہدایات بھی استعمال کر سکتے ہیں: `#Tidy_Off`، `#Tidy_On`، `#Tidy_ILC_Pos=nn`، `#Tidy_Parameters=...`۔

## ان انسٹال

`C:\Program Files\Notepad++\plugins\AutoItBeautify\` حذف کریں اور Notepad++ دوبارہ چلائیں۔
