# مُنسِّق AutoIt Tidy لـ Notepad++

[English](README.md) · [中文](README.zh-CN.md) · [हिन्दी](README.hi.md) · [Español](README.es.md) · [Français](README.fr.md) · [العربية](README.ar.md) · [বাংলা](README.bn.md) · [Português](README.pt.md) · [Русский](README.ru.md) · [اردو](README.ur.md)

تنسيق أكواد AutoIt بنقرة واحدة من **شريط أدوات Notepad++**، باستخدام **‏`Tidy.exe` الرسمي من AutoIt3** (SciTE4AutoIt3 الإصدار 21.316.1639.1).
النتيجة مطابقة للضغط على **Ctrl+T** داخل SciTE؛ ولا تحتوي الإضافة على أي منطق تنسيق خاص بها.

## المزايا

| الميزة | السلوك |
| --- | --- |
| المحرّك | **فقط** ‏`Tidy.exe` الرسمي المضمّن في `plugins\AutoItBeautify\tidy\` |
| النطاق | تنسيق **مخزن المحرّر الحالي فقط**؛ لا يقرأ ملفك ولا يحفظه |
| نقرة واحدة | زر في الشريط + أمر في القائمة؛ بلا نوافذ حوارية لملفات `.au3` |
| تراجع واحد | التنسيق كله خطوة تراجع واحدة → **Ctrl+Z** واحدة تعيد كل شيء |
| سجل التغييرات | الشريط البرتقالي يظهر **فقط على الأسطر التي تغيّرت فعلاً** |
| نهايات الأسطر | يُحافظ على نمط EOL الأصلي للمستند (LF / CRLF / CR) |
| الترميز | المخزن بترميز UTF-8؛ التعليقات غير اللاتينية محفوظة |
| لا تغييرات | إذا أفاد Tidy بـ «no updates to make» يبقى المخزن دون تغيير |
| المؤشر | يُحافظ على موضع المؤشر والتحديد والتمرير قدر الإمكان |

يطبّق Tidy قواعده الرسمية: الإزاحة (علامات جدولة افتراضياً)، توحيد حالة أحرف الكلمات المفتاحية/الدوال/المتغيرات،
المسافات حول الفواصل، إزالة المسافات في نهاية السطر، إضافة `EndFunc   ;==>FunctionName` تلقائياً،
مزامنة تعليقات `#Region`/`#CE`، وتنبيهات بنيوية مثل `;### Tidy Error`.

## التحقق مقابل Tidy الرسمي

* **318 ملفاً حقيقياً `.au3`**: المحتوى **متطابق 100%** مع تشغيل `Tidy.exe` الرسمي.
* 317 منها **متطابقة بايت ببايت** (بما في ذلك نهايات الأسطر).
* ملف واحد يختلف فقط في نمط نهاية السطر (فهو LF والإضافة تحافظ على LF، بينما يكتب Tidy دائماً CRLF).

## التثبيت

1. نزّل [Notepad-autoit-format (ZIP)](https://github.com/123d56/Notepad-autoit-format/archive/refs/heads/main.zip).
2. فك الضغط ثم **انقر بزر الفأرة الأيمن على `install.ps1` → Run with PowerShell**.
   يحدّد السكربت مسار Notepad++ تلقائياً ويطلب صلاحيات UAC عند الحاجة.
   بديل يدوي: انسخ مجلد `AutoItBeautify` إلى `C:\Program Files\Notepad++\plugins\`.
3. **أغلق Notepad++ تماماً ثم أعد تشغيله** — سيظهر الزر الأزرق في أقصى يمين شريط الأدوات.

## الاستخدام

* زر الشريط الأزرق، أو القائمة **Plugins → AutoIt 美化 → 一键美化 AutoIt 代码（Tidy）** (أسماء القوائم بالصينية؛ معرّف الأمر 22000).
* يعرض شريط الحالة النتيجة؛ و**Ctrl+Z** تلغي التنسيق كله في خطوة واحدة.
* اختياري: عيّن اختصاراً من **Settings → Shortcut Mapper → Plugin commands**.

## خيارات Tidy

حرّر `%APPDATA%\Notepad++\plugins\Config\AutoItBeautify\tidy\Tidy.ini` (يُنشأ تلقائياً عند أول استخدام).

```ini
tabchar=0          ; 0 = علامات جدولة، >0 = عدد المسافات
tabsize=4
proper=1           ; توحيد حالة الكلمات المفتاحية/الدوال
vars=3             ; المتغيرات: 1 كبيرة، 2 صغيرة، 3 كما ظهرت أولاً
delim=1            ; مسافات حول الفواصل والمعاملات
endfunc_comment=1  ; إضافة "EndFunc ;==>Name" (-1 = تعطيل)
icl_pos=0          ; عمود التعليق المضمّن: 0 = الإبقاء على الحالي
```

يمكنك أيضاً استخدام توجيهات Tidy داخل السكربت: `#Tidy_Off`، `#Tidy_On`، `#Tidy_ILC_Pos=nn`، `#Tidy_Parameters=...`.

## الإزالة

احذف `C:\Program Files\Notepad++\plugins\AutoItBeautify\` ثم أعد تشغيل Notepad++.
