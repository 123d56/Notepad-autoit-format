# Notepad++ के लिए AutoIt Tidy फ़ॉर्मैटर

[English](README.md) · [中文](README.zh-CN.md) · [हिन्दी](README.hi.md) · [Español](README.es.md) · [Français](README.fr.md) · [العربية](README.ar.md) · [বাংলা](README.bn.md) · [Português](README.pt.md) · [Русский](README.ru.md) · [اردو](README.ur.md)

**Notepad++ टूलबार** से एक क्लिक में AutoIt कोड सुधारें — यह **आधिकारिक AutoIt3 `Tidy.exe`** (SciTE4AutoIt3 v21.316.1639.1) चलाता है।
परिणाम SciTE में **Ctrl+T** दबाने के बराबर है; प्लगइन में अपना कोई फ़ॉर्मैटिंग लॉजिक नहीं है।

## विशेषताएँ

| विशेषता | व्यवहार |
| --- | --- |
| इंजन | केवल आधिकारिक `Tidy.exe` (प्लगइन के `tidy\` फ़ोल्डर में) |
| दायरा | केवल **वर्तमान एडिटर बफ़र**; फ़ाइल पढ़ता/सहेजता नहीं |
| एक क्लिक | टूलबार बटन + मेन्यू कमांड; `.au3` दस्तावेज़ों के लिए कोई डायलॉग नहीं |
| एकल अनडू | पूरा फ़ॉर्मैटिंग एक ही अनडू चरण → एक **Ctrl+Z** से सब वापस |
| परिवर्तन इतिहास | नारंगी पट्टी **केवल बदली गई पंक्तियों** पर दिखती है |
| लाइन एंडिंग | दस्तावेज़ की मूल EOL (LF / CRLF / CR) सुरक्षित रहती है |
| एन्कोडिंग | UTF-8 बफ़र; गैर-ASCII टिप्पणियाँ सुरक्षित |
| कोई बदलाव न हो तो | Tidy के "no updates" पर बफ़र अछूता रहता है |
| कर्सर | कर्सर/चयन/स्क्रॉल यथासंभव सुरक्षित |

Tidy के आधिकारिक नियम लागू होते हैं: इंडेंटेशन (डिफ़ॉल्ट टैब), कीवर्ड/फ़ंक्शन/वेरिएबल का केस, डिलिमिटर के आसपास स्पेस,
पंक्ति के अंत के स्पेस हटाना, स्वतः `EndFunc   ;==>FunctionName`, `#Region`/`#CE` टिप्पणी समन्वय, और `;### Tidy Error` जैसे संरचनात्मक संकेत।

## आधिकारिक Tidy से सत्यापन

* **318 वास्तविक `.au3` फ़ाइलें**: सामग्री आधिकारिक `Tidy.exe` के आउटपुट से **100 % समान**।
* इनमें 317 फ़ाइलें **बाइट-दर-बाइट समान** (लाइन एंडिंग सहित)।
* 1 फ़ाइल केवल लाइन एंडिंग में भिन्न है (वह LF है; प्लगइन LF रखता है, Tidy सदैव CRLF लिखता है)।

## स्थापना

1. [Notepad-autoit-format (ZIP)](https://github.com/123d56/Notepad-autoit-format/archive/refs/heads/main.zip) डाउनलोड करें।
2. अनज़िप करें, फिर **`install.ps1` पर राइट-क्लिक → Run with PowerShell**।
   स्क्रिप्ट Notepad++ स्वतः ढूँढती है और आवश्यकता पर UAC एलिवेशन माँगती है।
   मैनुअल: `AutoItBeautify` फ़ोल्डर को `C:\Program Files\Notepad++\plugins\` में कॉपी करें।
3. **Notepad++ पूरी तरह बंद करके पुनः खोलें** — टूलबार के दाएँ छोर पर नीला बटन दिखेगा।

## उपयोग

* टूलबार बटन, या मेन्यू **Plugins → AutoIt 美化 → 一键美化 AutoIt 代码（Tidy）** (मेन्यू नाम चीनी में है; कमांड ID 22000)।
* स्टेटस बार परिणाम दिखाता है; **Ctrl+Z** से पूरा फ़ॉर्मैटिंग एक चरण में वापस।
* वैकल्पिक: **Settings → Shortcut Mapper → Plugin commands** में शॉर्टकट निर्धारित करें।

## Tidy विकल्प

`%APPDATA%\Notepad++\plugins\Config\AutoItBeautify\tidy\Tidy.ini` संपादित करें (पहले उपयोग पर स्वतः बनती है)।

```ini
tabchar=0          ; 0 = टैब, >0 = स्पेस की संख्या
tabsize=4
proper=1           ; कीवर्ड/फ़ंक्शन केस सामान्यीकरण
vars=3             ; वेरिएबल केस: 1 अपर, 2 लोअर, 3 पहली बार जैसा
delim=1            ; डिलिमिटर के आसपास स्पेस
endfunc_comment=1  ; "EndFunc ;==>Name" जोड़ें (-1 = बंद)
icl_pos=0          ; इनलाइन टिप्पणी कॉलम: 0 = वर्तमान रखें
```

स्क्रिप्ट में Tidy निर्देश भी: `#Tidy_Off`, `#Tidy_On`, `#Tidy_ILC_Pos=nn`, `#Tidy_Parameters=...`।

## अनइंस्टॉल

`C:\Program Files\Notepad++\plugins\AutoItBeautify\` हटाएँ और Notepad++ पुनः खोलें।
