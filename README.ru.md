# Форматтер AutoIt Tidy для Notepad++

[English](README.md) · [中文](README.zh-CN.md) · [हिन्दी](README.hi.md) · [Español](README.es.md) · [Français](README.fr.md) · [العربية](README.ar.md) · [বাংলা](README.bn.md) · [Português](README.pt.md) · [Русский](README.ru.md) · [اردو](README.ur.md)

Форматирование AutoIt **одним нажатием на панели инструментов Notepad++** с помощью **официального `Tidy.exe` из AutoIt3** (SciTE4AutoIt3 v21.316.1639.1).
Результат идентичен нажатию **Ctrl+T** в SciTE — в плагине **нет собственной логики форматирования**.

## Возможности

| Возможность | Поведение |
| --- | --- |
| Движок | **Только** официальный `Tidy.exe` из `plugins\AutoItBeautify\tidy\` |
| Область | Форматирует **только текущий буфер**; файл не читается и не сохраняется |
| Одно нажатие | Кнопка на панели + команда меню; для `.au3` без диалогов |
| Одна отмена | Всё форматирование — один шаг → один **Ctrl+Z** возвращает всё |
| История изменений | Оранжевая полоса появляется **только на реально изменённых строках** |
| Переводы строк | Сохраняется исходный стиль EOL документа (LF / CRLF / CR) |
| Кодировка | Буферы в UTF-8; не-ASCII комментарии сохраняются |
| Нет изменений | Если Tidy сообщает «no updates to make», буфер не трогается |
| Курсор | Позиция курсора, выделение и прокрутка сохраняются по возможности |

Tidy применяет свои официальные правила: отступы (по умолчанию табуляция), нормализация регистра ключевых слов/функций/переменных,
пробелы вокруг разделителей, удаление пробелов в конце строк, автоматическое `EndFunc   ;==>ИмяФункции`,
синхронизация комментариев `#Region`/`#CE`, а также предупреждения вида `;### Tidy Error`.

## Проверка соответствия официальному Tidy

* **318 реальных файлов `.au3`**: содержимое **совпадает на 100 %** с результатом официального `Tidy.exe`.
* 317 из них **побайтово идентичны** (включая переводы строк).
* 1 файл отличается только стилем перевода строки (он в LF; плагин сохраняет LF, а Tidy всегда пишет CRLF).

## Установка

1. Скачайте [Notepad-autoit-format (ZIP)](https://github.com/123d56/Notepad-autoit-format/archive/refs/heads/main.zip).
2. Распакуйте и **щёлкните правой кнопкой по `install.ps1` → Выполнить с PowerShell**.
   Скрипт сам находит Notepad++ и запрашивает UAC, если нужна запись в `Program Files`.
   Вручную: скопируйте папку `AutoItBeautify` в `C:\Program Files\Notepad++\plugins\`.
3. **Полностью закройте Notepad++ и запустите снова** — синяя кнопка появится справа на панели инструментов.

## Использование

* Синяя кнопка на панели или меню **Plugins → AutoIt 美化 → 一键美化 AutoIt 代码（Tidy）** (названия на китайском; ID команды 22000).
* Строка состояния показывает результат; **Ctrl+Z** отменяет всё за один шаг.
* Необязательно: назначьте сочетание клавиш в **Settings → Shortcut Mapper → Plugin commands**.

## Параметры Tidy

Отредактируйте `%APPDATA%\Notepad++\plugins\Config\AutoItBeautify\tidy\Tidy.ini` (создаётся при первом использовании).

```ini
tabchar=0          ; 0 = табуляция, >0 = число пробелов
tabsize=4
proper=1           ; нормализация регистра ключевых слов/функций
vars=3             ; переменные: 1 ВЕРХ, 2 нижн, 3 как при первом появлении
delim=1            ; пробелы вокруг разделителей
endfunc_comment=1  ; добавлять "EndFunc ;==>Имя" (-1 = отключить)
icl_pos=0          ; колонка комментария в строке: 0 = сохранять
```

В скрипте доступны директивы Tidy: `#Tidy_Off`, `#Tidy_On`, `#Tidy_ILC_Pos=nn`, `#Tidy_Parameters=...`.

## Удаление

Удалите `C:\Program Files\Notepad++\plugins\AutoItBeautify\` и перезапустите Notepad++.
