# Notepad++-এর জন্য AutoIt Tidy ফরম্যাটার

[English](README.md) · [中文](README.zh-CN.md) · [हिन्दी](README.hi.md) · [Español](README.es.md) · [Français](README.fr.md) · [العربية](README.ar.md) · [বাংলা](README.bn.md) · [Português](README.pt.md) · [Русский](README.ru.md) · [اردو](README.ur.md)

**Notepad++ টুলবার** থেকে এক ক্লিকে AutoIt কোড ফরম্যাট করুন — এটি চালায় **অফিসিয়াল AutoIt3 `Tidy.exe`** (SciTE4AutoIt3 v21.316.1639.1)।
ফলাফল SciTE-এ **Ctrl+T** চাপার সমান; প্লাগইনে নিজস্ব কোনো ফরম্যাটিং লজিক নেই।

## বৈশিষ্ট্য

| বৈশিষ্ট্য | আচরণ |
| --- | --- |
| ইঞ্জিন | শুধুমাত্র অফিসিয়াল `Tidy.exe` (`plugins\AutoItBeautify\tidy\`-তে অন্তর্ভুক্ত) |
| পরিসর | শুধু **বর্তমান এডিটর বাফার** ফরম্যাট করে; ফাইল পড়ে বা সেভ করে না |
| এক ক্লিক | টুলবার বোতাম + মেনু কমান্ড; `.au3` ডকুমেন্টে কোনো ডায়ালগ নেই |
| একক আনডু | পুরো ফরম্যাটিং এক ধাপ → এক **Ctrl+Z**-তে সব ফিরে আসে |
| পরিবর্তনের ইতিহাস | কমলা বার **শুধু সত্যিই পরিবর্তিত লাইনগুলোতে** দেখায় |
| লাইন এন্ডিং | ডকুমেন্টের নিজস্ব EOL (LF / CRLF / CR) সংরক্ষিত থাকে |
| এনকোডিং | বাফার UTF-8; non-ASCII মন্তব্য অক্ষত থাকে |
| পরিবর্তন নেই | Tidy «no updates to make» বললে বাফার অপরিবর্তিত থাকে |
| কার্সর | কার্সর/সিলেকশন/স্ক্রল যথাসম্ভব সংরক্ষিত |

Tidy-র অফিসিয়াল নিয়ম প্রযোজ্য: ইনডেন্টেশন (ডিফল্ট ট্যাব), কীওয়ার্ড/ফাংশন/ভেরিয়েবলের কেস,
ডেলিমিটারের চারপাশে স্পেস, লাইনের শেষে স্পেস অপসারণ, স্বয়ংক্রিয় `EndFunc   ;==>FunctionName`,
`#Region`/`#CE` মন্তব্য সমন্বয়, এবং `;### Tidy Error`-এর মতো কাঠামোগত সতর্কতা।

## অফিসিয়াল Tidy-র সাথে যাচাই

* **318টি বাস্তব `.au3` ফাইল**: বিষয়বস্তু অফিসিয়াল `Tidy.exe`-এর আউটপুটের সাথে **100% অভিন্ন**।
* এর মধ্যে 317টি **বাইট-বাই-বাইট অভিন্ন** (লাইন এন্ডিংসহ)।
* 1টি ফাইল শুধু লাইন এন্ডিং শৈলীতে আলাদা (এটি LF; প্লাগইন LF রাখে, Tidy সর্বদা CRLF লেখে)।

## ইনস্টল

1. [Notepad-autoit-format (ZIP)](https://github.com/123d56/Notepad-autoit-format/archive/refs/heads/main.zip) ডাউনলোড করুন।
2. আনজিপ করে **`install.ps1`-এ রাইট-ক্লিক → Run with PowerShell**।
   স্ক্রিপ্ট Notepad++ খুঁজে নেয় এবং প্রয়োজনে UAC elevation চায়।
   ম্যানুয়াল: `AutoItBeautify` ফোল্ডারটি `C:\Program Files\Notepad++\plugins\`-এ কপি করুন।
3. **Notepad++ সম্পূর্ণ বন্ধ করে আবার চালু করুন** — টুলবারের ডান প্রান্তে নীল বোতাম দেখা যাবে।

## ব্যবহার

* টুলবারের নীল বোতাম, অথবা মেনু **Plugins → AutoIt 美化 → 一键美化 AutoIt 代码（Tidy）** (মেনুর নাম চীনা; কমান্ড ID 22000)।
* স্ট্যাটাস বার ফলাফল দেখায়; **Ctrl+Z** এক ধাপে সব ফিরিয়ে দেয়।
* ঐচ্ছিক: **Settings → Shortcut Mapper → Plugin commands**-এ শর্টকাট দিন।

## Tidy অপশন

`%APPDATA%\Notepad++\plugins\Config\AutoItBeautify\tidy\Tidy.ini` সম্পাদনা করুন (প্রথম ব্যবহারে স্বয়ংক্রিয়ভাবে তৈরি হয়)।

```ini
tabchar=0          ; 0 = ট্যাব, >0 = স্পেস সংখ্যা
tabsize=4
proper=1           ; কীওয়ার্ড/ফাংশন কেস স্বাভাবিকীকরণ
vars=3             ; ভেরিয়েবল: 1 বড়, 2 ছোট, 3 প্রথমবার যেভাবে ছিল
delim=1            ; ডেলিমিটারের চারপাশে স্পেস
endfunc_comment=1  ; "EndFunc ;==>Name" যোগ করে (-1 = বন্ধ)
icl_pos=0          ; ইনলাইন মন্তব্য কলাম: 0 = বর্তমান রাখুন
```

স্ক্রিপ্টে Tidy নির্দেশও ব্যবহার করা যায়: `#Tidy_Off`, `#Tidy_On`, `#Tidy_ILC_Pos=nn`, `#Tidy_Parameters=...`।

## আনইনস্টল

`C:\Program Files\Notepad++\plugins\AutoItBeautify\` মুছে ফেলে Notepad++ পুনরায় চালু করুন।
